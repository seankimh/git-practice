# Interesting Software Engineering Article

## Article

[I Rebuilt the Game I Wrote on a PlayStation 2 at Age 14](https://www.therandomcoder.com/posts/rebuilding-my-playstation-2-game-at-age-14)

## Why I Found It Interesting

I found this article interesting because the author originally created a game on a PlayStation 2 when he was fourteen, but the original source code was eventually lost. The only version he still had was a PDF containing screenshots of the code displayed on an old CRT monitor. Years later, he was able to use AI to interpret those screenshots and reconstruct a working version of the game.

I also thought it was interesting because it shows how much software development tools have changed. The original game was made without modern tools like version control, powerful debuggers, or easy online publishing. Today, the same project can be restored, improved, and made available on the web much more easily. It is a strange example, but it shows how improvements in development tools can completely change what programmers are able to build and preserve.
